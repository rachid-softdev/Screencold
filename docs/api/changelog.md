# API Changelog

## v1 (Current)

Initial release. All endpoints under `/api/v1/`.

### Endpoints

| Method | Path                   | Description              |
|--------|------------------------|--------------------------|
| GET    | /api/v1/audits         | List user audits         |
| POST   | /api/v1/audits         | Create a new audit       |
| GET    | /api/v1/audits/:id     | Get audit details        |
| GET    | /api/v1/campaigns      | List user campaigns      |
| POST   | /api/v1/campaigns      | Create a campaign        |
| GET    | /api/v1/credits        | Get credit info          |
| GET    | /api/v1/health         | Health check             |
