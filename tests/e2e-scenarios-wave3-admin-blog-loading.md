## 6. Admin & Observability

> **Prerequisite for all scenarios in this section:** User must be logged in with role `ADMIN`. Non-admin users or unauthenticated visitors must be redirected away. All scenarios in this section are P1-P2.

### Admin Access Control

| Prio | Cat | Test Name | Description |
|------|-----|-----------|-------------|
| P1 | Success | Admin_observability_loads_for_admin | Login as admin user, navigate to /admin/observability → page renders with header "Observabilité", 4 status cards (Worker, Last Updated, Total Rate, Errors), RED metrics table, duration sparkline section visible |
| P1 | Error | Admin_observability_redirects_non_admin | Login as non-admin user (FREE/PRO without ADMIN role), navigate to /admin/observability → client-side redirect to /login, admin page content never rendered |
| P1 | Error | Admin_observability_redirects_unauthenticated | Clear session, navigate to /admin/observability → redirect to /login, admin page content never rendered |
| P2 | Edge | Admin_observability_role_check_on_mount | Login as non-admin user, navigate to a non-protected page (e.g. /dashboard), then programmatically navigate to /admin/observability → immediate redirect away, no metrics fetch fired |
