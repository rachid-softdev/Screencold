### PATCH /api/email-templates/:id

| Prio | Cat | Test Name | Description |
|------|-----|-----------|-------------|
| P0 | Success | Templates_update_name | PATCH existing user template with `{name: "New Name"}` → 200, name updated |
| P1 | Success | Templates_update_set_default | PATCH with `{isDefault: true}` → old default cleared, this template becomes default |
| P1 | Success | Templates_update_partial_fields | PATCH with only `{subject: "New subject"}` → only subject changed, other fields unchanged |
| P0 | Error | Templates_update_nonexistent | PATCH non-existent id → 404 `NOT_FOUND` |
| P0 | Error | Templates_update_another_users_template | PATCH another user's template id → 403 `FORBIDDEN` (template.userId !== null and !== userId) |
| P1 | Error | Templates_update_global_template_owned_by_null | PATCH a global template (`userId: null`) — 404 or allowed? This might need investigation → verify whether global templates can be PATCHed. |
