|------|-----|-----------|-------------|

## Existing Coverage (Wave 3) — NOT duplicated

The following billing/credit scenarios are already tested in Wave 3 and excluded from Wave 4:

- `api-routes.spec.ts`: Billing transactions API (401, empty, pagination structure), Credits checkout (401, invalid package, missing/negative credits), Stripe checkout (empty plan), Cron reset credits, Stripe webhook
- `settings-edge.spec.ts`: billing page loads (plan, status, usage visible), empty transaction history, buy credits redirects to Stripe, toggle monthly/annual
- `admin-blog-loading.spec.ts`: credit counter shows balance, credit counter low credits warning
- `public-pages.spec.ts`: pricing page billing toggle (default monthly, to annual, back to monthly)
- `settings-api.spec.ts`: GET /api/v1/credits (unauthorized + with session)
